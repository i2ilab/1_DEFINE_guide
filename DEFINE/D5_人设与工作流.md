# D5 · 人设与工作流(Feature-2)—— 把设计收成一张卡

> **目标**:写出 agent 的人设(三段式)、工作流(触发/循环/工具/边界)、记忆方案,把 DEFINE 六步收成**一张设计卡**。
> **前置输入**:D4 的 PRD 与边界(T4)。
> **产出物**:`templates/T5_DEFINE设计卡.md` 填完(本模块 DEFINE 支柱的总产出)。
> **配套 skill**:`/define-flow`｜**示例**:`example_project/小智_DEFINE.md`

## 先打个气:这一步,你在给 agent「立人」

人设(persona)不是玄学。你学过人格、学过咨询关系里的「一致性/真诚」——**给 agent 定「它是谁、怎么说话、守什么」,和你理解一个咨询师的专业角色,是同一件事。** 这一步做完,你的 agent 就从「一个会说话的模型」变成「一个有身份、有边界的专业陪伴者」。

## 新想法:人设三段式 —— 身份 / 语气 / 边界

系统提示(system prompt)的核心,是三段:

1. **身份**:你是谁?为谁服务?(例:「你是林晓雨的深夜情绪陪伴者,不是治疗师。」)
2. **语气**:怎么说话?(例:「温和、简短、先接情绪再谈方法;不评判、不说教。」)
3. **边界**:守什么红线?(例:「不诊断、不开药;识别到危机信号,立即停止练习并给出真人求助资源。」)

**三段式的顺序有讲究**:先立身份(它才知道自己是谁),再定语气(它才知道怎么说),最后钉边界(它才知道哪里必须停)。边界永远写在最后、写得最硬。

## 新想法:工作流 —— 触发 / 循环 / 工具 / 边界

人设是「它是谁」,工作流是「它怎么干活」。呼应你在模块 0/1 学的 Harness,一个 agent 的工作流是四件套:

| 件 | 是什么 | 心理陪伴例子 |
|---|---|---|
| **触发** | 什么时候启动、进入哪个流程 | 用户打开 → 先问「现在感觉怎么样」 |
| **循环** | 每一轮怎么走(读状态→决定→说话→自检) | 读情绪状态 → 选下一步(倾听/练习/转介)→ 回应 → 安全自检 |
| **工具** | 它能调用什么 | 呼吸练习脚本、量表、危机资源库、`safety_check` |
| **边界** | 每一轮的安全阀 | 每句发出前过一遍 `safety_check`,红灯就拦 |

## 新想法:三种记忆 + safety_check

**三种记忆**(认知心理学 Tulving 的经典分类,你们学过):

- **情景记忆**:具体发生过什么(这个用户上次说和室友吵架了)。
- **语义记忆**:一般知识(CBT 流程、某量表怎么算)。
- **程序记忆**:怎么做一件事(一次陪伴的固定套路)。

**心理/教育场景一律用化名存储,不采集真实身份**(接 D4 红黄绿)。

**safety_check** 是每个心理 agent 都必须有的工具,用**红黄绿分级**:🟢 正常倾听 / 🟡 需要留意 / 🔴 危机信号 → **静默上报真人 / 给出热线,绝不自行处理**。

## 操作步骤

1. **写人设三段式**(T5 人设栏):身份、语气、边界,边界写最硬。
2. **列工作流四件套**(T5 工作流栏):触发、循环、工具、边界各写清。
3. **定记忆方案**:三种记忆各存什么、怎么化名(T5 记忆栏)。
4. **配 safety_check**:红黄绿各对应什么信号、什么动作。
5. **收成设计卡**:把 D1–D5 的产出,一次性填进 T5 的六栏(D/E/F/I/N/E)+ 安全栏。这张卡就是你交给 `2_hcai_guide` h4/h5 的「参考答案级」输入。
6. **对照示例**:打开 `example_project/小智_DEFINE.md`,看一张真实的设计卡长什么样——**看颗粒度,别照抄**。

## 痛点对比

| 😌 简单·看不出必要 | 系统提示写一句「你是一个友善的心理助手,帮用户缓解情绪」——能跑就行 |
|---|---|
| 🔥 复杂·痛点凸显 | 测试时:用户说「我想消失」,agent 回「每个人都有低谷,加油哦😊」——因为人设里没有「边界」段、工作流里没有 `safety_check`。一句温暖的废话,在危机时刻就是**失职**。而三段式 + safety_check 的 agent,会立刻停下练习、给出真人求助资源 |

## 门禁检查(DEFINE 支柱完成)

- [ ] T5 设计卡六栏 + 安全栏填完
- [ ] 人设三段式齐全,边界写在最后、写得最硬
- [ ] 工作流四件套(触发/循环/工具/边界)都写清
- [ ] 三种记忆方案 + 化名存储说明
- [ ] `safety_check` 红黄绿各对应信号与动作,危机 → 转真人
- [ ] 对照过小智示例,确认自己的卡颗粒度到位

## 思考题

> 你的设计卡做完了。现在最后一问:**你凭什么说它「有用、安全」?**
> ——你现在只有「设计」,还没有「证据」。这正是下一个支柱 Eval 要解决的:把「我觉得它不错」变成「我有证据证明它行」。翻到 `EVAL/E0`。

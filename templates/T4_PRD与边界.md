# T4 · PRD 与边界

> **怎么用**:配合 `DEFINE/D4_PRD与边界.md`。一页足矣;**边界和数据红黄绿是重点**。

## 1. 一页 PRD · 六要素

| 要素 | 内容 |
|---|---|
| ① 一句话定位 | 【例:一个深夜陪考前焦虑学生做 3 分钟正念的情绪陪伴 agent】 |
| ② 目标用户 | 【接 T2 主画像】 |
| ③ 核心功能(接刚性层) | 【例:情绪接住 → 引导式呼吸/正念 → 温和收尾】 |
| ④ **明确不做** | 【例:不诊断、不开药、不替代咨询、不处理危机(转真人)、不留住用户】 |
| ⑤ 成功标准 | 【例:用户练习后自评焦虑下降;危机场景 100% 正确转介】 |
| ⑥ 主要风险 | 【例:漏识别危机、制造依赖、语气不当】 |

## 2. 边界三问

- **能做什么?** 【】
- **明确不做什么?** 【】
- **何时必须转人?**(信号 → 动作 → 转给谁) 【】

## 3. 数据红黄绿清单

| 数据 | 灯 | 处理方式 |
|---|---|---|
| 【例:用户真实姓名/学号】 | 🔴 红 | 【不采集】 |
| 【例:对话内容】 | 🟡 黄 | 【化名、最小化、明确告知、可删除】 |
| 【例:公开量表题、科普知识】 | 🟢 绿 | 【正常使用】 |

## 4. HAX 18 抽检(挑 5 条对照 PRD,缺的补)

- [ ] G1 说清能做什么 —— 【开场白怎么写?】
- [ ] G2 说清能做多好(校准期望)—— 【】
- [ ] G8 能高效关闭 —— 【怎么退出?】
- [ ] G9 能高效纠正 —— 【说错了怎么改?】
- [ ] G11 说明为何这么做 —— 【】

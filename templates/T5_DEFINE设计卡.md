# T5 · DEFINE 设计卡(定义支柱总产出)

> **怎么用**:配合 `DEFINE/D5_人设与工作流.md`。这是 DEFINE 支柱的**总产出卡**——把 D1–D5 一次性收进来。它就是你带进 `2_hcai_guide` h4/h5 的「参考答案级」输入。对照 `example_project/小智_DEFINE.md` 看颗粒度。

## DEFINE 六栏 + 安全栏

| 栏 | 内容 |
|---|---|
| **D 域分析** | 【解决谁的什么问题;哪个专家环节缺席、被 AI 补位】 |
| **E 体验** | 【主画像一句话 + HMW + 一轮对话怎么走】 |
| **F 功能** | 【核心功能 + 需要的技能/工具/记忆】 |
| **I 实现** | 【用什么搭:s5 骨架 + c1–c4 能力(本模块不展开)】 |
| **N 测试** | 【打算怎么评?→ 交给 Eval 支柱(E1–E4)】 |
| **E 演化** | 【上线后靠什么发现问题、怎么迭代】 |
| 🔒 **安全** | 【红黄绿数据分级 + 危机处理:信号→停止→转真人】 |

## 人设 · 三段式(system prompt 核心)

1. **身份**:【你是谁?为谁服务?"我不是治疗师"】
2. **语气**:【怎么说话?温和/简短/先接情绪/不评判】
3. **边界**(写最硬):【不诊断/不开药;危机→停止+转真人】

## 工作流 · 四件套

| 件 | 内容 |
|---|---|
| 触发 | 【什么时候启动、进哪个流程】 |
| 循环 | 【每轮:读状态 → 决定 → 说话 → 自检】 |
| 工具 | 【能调什么:练习脚本/量表/危机资源库/safety_check】 |
| 边界 | 【每轮的安全阀:发出前过 safety_check】 |

## 三种记忆(化名存储)

- 情景:【记住什么具体经历】
- 语义:【存什么知识/流程】
- 程序:【固定的陪伴套路】

## safety_check · 红黄绿

| 灯 | 信号 | 动作 |
|---|---|---|
| 🟢 | 【正常倾听/练习】 | 正常回应 |
| 🟡 | 【情绪走低/需留意】 | 更克制、关注 |
| 🔴 | 【自伤/自杀/暴力信号】 | **停止 + 给真人/热线,绝不自行处理** |

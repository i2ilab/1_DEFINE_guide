# E0 · 总览 —— 能跑 ≠ 能用 ≠ 该用

> **目标**:理解为什么 LLM agent 特别难评、为什么心理/教育对评估要求特别高,并认出这是**你的主场**。
> **前置输入**:你有一个能跑的 agent(DEFINE 支柱做完更好)。

## 先打个气:评估是心理学生的主场

一听「评估」,别想成写代码测试。评估的核心问题是——**怎么科学地测量一个看不见的东西(共情、安全、专业性)?** 这正是心理测量学干了一百年的事。**信度、效度、量表设计、盲评——你受过的训练,工程师没有。** 这一支柱,你是主角。

## 新想法:能跑 ≠ 能用 ≠ 该用

三个层次,一个比一个高:

- **能跑**:它不报错、能返回一段话。(工程师的及格线)
- **能用**:它返回的话**有用、体验好**。(产品的及格线)
- **该用**:它在心理/教育这种高风险场景里**安全、不越界**。(专业的及格线)

新手止步于「能跑」,以为做完了。**真正的工作,从「能跑」之后才开始。**

## 新想法:为什么 LLM agent 特别难评

传统软件好测:输入确定 → 输出确定,写几个用例跑一遍,对就是对。LLM agent 完全不同——五个难点:

| 难点 | 意思 |
|---|---|
| **黑盒** | 你不知道它内部为什么这么答 |
| **概率** | 同一问题问三次,答案可能都不一样 |
| **无限空间** | 用户可能说任何话,输出没有标准答案 |
| **语义失败** | 语法完美、听起来流畅,但意思是错的、甚至有害 |
| **误差传播** | 多步任务里,前一步的小错被后面放大 |

这五点,让「跑几个测试用例」失效。评估 LLM agent,需要更像「**科学实验**」的方法——而做实验,是你的老本行。

## 新想法:在心理/教育,失败 = 真实伤害

为什么这个领域对评估要求特别高?因为**失败不是「体验不好」,是真实伤害**:

- **错建议**:用温暖流畅的语气,给出一条错误的心理建议——**越流畅越危险**,用户更容易信。
- **漏危机**:没识别求助信号,可能酿成真实事故。
- **放大偏见**:训练数据的偏见,让它对某些人群系统性更不友好。

反复记住一句:**流畅温暖 ≠ 安全。** 两个反例听起来都「很好」,却都危险。你们受过「不伤害(do no harm)」的训练——评估,就是守护这条线。

## 新想法:评估三问 + 信度效度

把评估拆简单,就是系统回答三个问题:

> **有用吗?**(任务完成了吗、质量如何)　**安全吗?**(会不会伤害、漏危机)　**稳定吗?**(换个说法、换个人评,还一样吗)

而回答它们的核心工具,你早就学过:

- **信度(reliability)**——稳不稳。同样输入,结果一致吗?换个评委打分还一样吗?
- **效度(validity)**——准不准。你的指标,测的真是你想测的吗?
  > **反例**:你想测「共情能力」,但你的题其实只测了「用词是否礼貌」——那就是**效度不足**。一个只会说「我理解你的感受」的 agent 能拿高分,但它根本没共情。

**把心理测量那套「怎么科学地测看不见的东西」搬来评 agent——这是你的主场。**

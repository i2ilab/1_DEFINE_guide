# 示例项目 —— 三个真实项目的 DEFINE + Eval 拆解

> **看颗粒度,别照抄。** 这里把老师三个真实在跑的项目,按本模块的两支柱(DEFINE 定义 / Eval 评估)拆开写给你看——不是让你抄内容,是让你看清「一张设计卡、一份评估报告该细到什么程度」。你的项目内容必须是你自己的。
> 助教手里有原始文档,照抄一眼看穿。

## 三个项目,三种「打开方式」

三个项目不是随便选的——它们分别把 DEFINE 六步里的不同环节做到了极致,正好当你三份不同侧重的「参考答案」。

| 项目 | 一句话定位 | 最亮的一步 | 去看哪个文件学什么 |
|---|---|---|---|
| **小智**(Reading Bot) | 给凉山山区孩子的猫头鹰语言学伴 | **D·E·F 全流程范本** | `小智_DEFINE.md` 学怎么从域分析走到设计卡;`小智_EVAL.md` 学怎么四维评估一个儿童教育 agent |
| **Agent Leo**(deepsy.ai) | 112 位心理学大师的数字分身 | **F 功能设计**:persona + 多 agent 编排 | `AgentLeo_DEFINE.md` 学怎么用一个文件承载一个「专家人设」、多 agent 怎么编排 |
| **HEAI** | 测量「人如何心理体验 AI」的研究型 agent | **N 测试评估**:强制引用 + red-team + 雷达 | `HEAI_EVAL.md` 学怎么设计反幻觉护栏、怎么用 red-team 和雷达图做严谨评估 |

## 建议的读法

- **第一次做项目,先读 `小智_DEFINE.md`。** 它把 DEFINE 的 D→E→F 完整走了一遍,对应 T1–T5 五个模板,是最完整的「六步范本」。读完你就知道每一张卡该填成什么样。
- **要做多角色 / 人设类项目**(如"和不同流派的咨询师对话"),加读 `AgentLeo_DEFINE.md`——它专讲怎么把一个专家写成一个 persona 文件,以及多个 agent 一起说话时怎么编排。
- **做评估、写评估报告卡壳时,读 `小智_EVAL.md` + `HEAI_EVAL.md`。** 前者示范怎么给一个真实 agent 打四维分、测危机;后者示范研究级的反幻觉设计和 red-team。
- 每个文件里的**分数都标注了「示例」**——它们是为了给你看颗粒度,不是真实测评结论。

## 一个提醒

三个项目都不是玩具:小智在联网运行,Agent Leo 上线在 deepsy.ai,HEAI 有整套 red-team 文档。它们证明一件事——**从一张设计卡到一个真实上线的产品,中间只隔着 DEFINE 和 Eval 这两步方法。** 你四天后也能走到这里。

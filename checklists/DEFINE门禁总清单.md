# DEFINE 门禁总清单

> 把 D1–D5 各阶段的门禁汇总成一张总表。**每过一关才进下一关**;全过了,DEFINE 支柱才算完成。
> 口诀:**六步齐、边界清、红黄绿分级过——没有安全红线的设计,不专业。**

## D1 域分析 → T1

- [ ] 挖了 ≥ 5 个真实痛点,每条有证据
- [ ] 说清了「专家怎么做 + 哪个环节缺席可补位」
- [ ] 三标准每项 ≥ 3 分,每分有证据
- [ ] 一句话选题套进标准句式,含一条安全红线
- [ ] 互测通过(别人能复述谁/场景/问题)

## D2 用户建模 → T2

- [ ] 主画像四要素具体到「能想象出画面」
- [ ] 写了一句话故事(某人卡住的那一刻)
- [ ] 写了一句 HMW,既锁定人/场景又留方案空间
- [ ] 互测:同学说得出「这个人需要什么」

## D3 需求与旅程 → T3

- [ ] 三层需求(刚性/情感/成长)都有,各附证据
- [ ] 区分了表面需求 vs 背后真需求
- [ ] 旅程地图每步标了痛点/情绪/AI 介入点
- [ ] 标出 ≥ 1 个**危机介入点**(信号→停止→转真人)
- [ ] 设计了**退场**(温和收尾、不制造依赖)

## D4 PRD 与边界 → T4

- [ ] 一页 PRD 六要素齐全,含「明确不做」
- [ ] 边界三问(能做/不做/何时转人)写死了
- [ ] 数据红黄绿清单列完,每类标处理方式
- [ ] 挑 5 条 HAX 抽检过,缺的补了
- [ ] D3 危机介入点都进了 PRD「何时转人」

## D5 人设与工作流 → T5(总产出)

- [ ] 设计卡六栏 + 安全栏填完
- [ ] 人设三段式齐全,边界写最后、最硬
- [ ] 工作流四件套(触发/循环/工具/边界)写清
- [ ] 三种记忆方案 + 化名存储
- [ ] safety_check 红黄绿各对应信号与动作,危机→转真人
- [ ] 对照过小智示例,颗粒度到位

---

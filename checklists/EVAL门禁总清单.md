# EVAL 门禁总清单

> 把 E1–E4 各阶段门禁汇总。**每过一关才进下一关**;全过了,Eval 支柱才算完成。
> 口诀:**四维齐评、危机全过、至少一轮迭代——安全一票否决。**

## E1 四维评估 → T6

- [ ] 四维 rubric(5 分/1 分标准)写清了
- [ ] 每维备了 3–5 个测试场景(含边界)
- [ ] 逐维打分,每分附证据
- [ ] 画了四维雷达,标出最短板
- [ ] 单独过了安全闸(PASS/FAIL)

## E2 三视角与 LLM 评委 → T6

- [ ] 每场景过程/工具/结果三视角都评了
- [ ] 理解「结果对 ≠ 过程对」
- [ ] 写了细 rubric,用**独立模型**当评委
- [ ] 抽样 ≥ 20% 人工复核,记了偏差
- [ ] 知道通用基准测不出你项目的真实安全

## E3 危机测试与红队 → T7

- [ ] 从用例库选了 8–12 条贴合场景的危机用例
- [ ] 逐条实测,记录实际输出
- [ ] 按「合格四条」判定 PASS/FAIL
- [ ] 做了课堂/同伴复核
- [ ] 每条 FAIL 写了修复动作
- [ ] 🔒 过了一票否决闸(全 PASS 才算安全通过)

## E4 迭代自检环 → T8

- [ ] 问题都列进 T8,并**归了层**
- [ ] 每个问题写了**诊断根因**(不是「再试一次」)
- [ ] 给危机场景加了「输出前安全复核」
- [ ] 跑了 ≥ 1 轮「测→改→再测」,记了改前改后
- [ ] T7 的危机 FAIL 都修复并复测 PASS
